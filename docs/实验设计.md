# 实验设计

## 数据流

真实仿真 -> coverage report -> `process_csv.py` -> canonical bin-by-run CSV -> DBSCAN/component clustering -> information scores -> UCB scheduler -> 每次真实仿真反馈 -> 更新 coverage state -> continuous refill。

## 主要口径

- 覆盖分子：冻结 manifest 中 hit=1 的 unique functional bins。
- 覆盖分母：同一 manifest 中 eligible functional bins；不得把 URG 汇总行重复计数。
- accumulated runtime：所有已完成仿真 runtime 之和。
- walltime：从第一提交到最后完成，包含并行、coverage extraction 和调度开销。
- 初始语料只用于建立历史命中和聚类信息；正式方法的新增覆盖奖励必须从 adaptive run 开始计算。

## 复现实验矩阵

每个方法均使用相同 initial corpus、logical batch size=10、logical batches=100、H=1000、P=10。先做一个 10-submit smoke，再做完整预算；smoke 不能写入正式结果目录。

## 失败处理

记录失败提交、重试、超时、许可证等待和 coverage 解析失败。任何方法的预算分母都必须同时报告 submitted、completed、failed 和 retried。
