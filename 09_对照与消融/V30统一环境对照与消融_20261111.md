## 运行前固定的协议

- 复用 V30 验收过的 simv、testbench、稳定 XML 解析和超时设置，不改变 RTL，不覆盖任何旧运行目录。
- 使用相同的 39 条初始向量、508/4507 初始并集、751 个 cluster、四种顶层序列、seed 42 的预注册仿真 seed 列表、1000 次提交、10 workers、logical batch size 10。
- 六种方法统一关闭额外参数定向 steering。这样移除 cluster 调度时不会同时改变可用的定向参数策略；保留 V30 build 中相同的正常序列参数范围。
- 每种方法先执行独立 30 次 smoke 并通过 UVM、事件/向量/奖励和原始 VDB URG 合并门禁，再从初始语料独立运行 1000 次。smoke 不计入正式预算，不允许失败重试或从中间覆盖接续。
- 正式结果接受失败尝试计入预算，但不奖励其覆盖；任何缺失真实日志、解析错误或审计不一致均停止后续流程并定位原因，不能通过删失败记录或追加预算修饰结果。

## 方法定义

| 方法 | 本地实现规则 |
| --- | --- |
| Full | 保留 V30 作者衍生两层 UCB、信息先验、互信息、运行时间惩罚与连续补位；只统一关闭 steering |
| NoIncrementalRefill | 其余 Full 逻辑不变；每 10 次提交组成同步批次，全部反馈后才启动下一批 |
| NoRuntimePenalty | 其余 Full 逻辑不变；同时去掉实际序列打分的动态惩罚和候选池打分的固定惩罚，保留实际 CPU 计时 |
| RandomSelection | 四种序列均匀有放回选择，不使用 cluster/sequence UCB；独立选择 RNG，不消耗仿真 seed RNG |
| SequenceUCBOnly | 无 cluster 选择、无 target steering；全局在线新增 bin 为序列奖励，保留相同序列探索系数和运行时间惩罚 |
| ClusterUCBOnly | 保留 cluster 调度；在该 cluster 的历史可达候选序列中均匀有放回选择，无序列 UCB；无历史支持则使用完整四序列池 |

论文未公开完整回归池、全部消融实现和作者 seed；以上为运行前固定的本地定义，不声称逐行等同论文。作者衍生 Full 尚含 MI、分阶段 cluster 选择和 80% 目标/20% 全局序列奖励等既有差异，本轮不趁消融改写 Full 算法。

## 验收与归档

每轮保存协议/源码哈希、逐次选择、仿真 seed、事件哈希链、反馈向量、CPU 和 walltime 曲线。逐份核查原始 UVM 日志的 PASS、完整 summary、ERROR/FATAL 数及非零时间；独立 URG 合并初始语料和成功在线 VDB，比较 4507 个定义与实际覆盖身份。所有方法完成后生成同协议总表和对比曲线。

完整日志、simv、VDB 和私有路径只留服务器。GitHub 仅同步脱敏数据、代码、哈希和报告。运行中或只完成 smoke 的方法不得标记为第九步完成。
