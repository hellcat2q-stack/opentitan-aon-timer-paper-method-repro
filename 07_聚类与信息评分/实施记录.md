# 阶段 07：聚类与信息评分：实施记录

## 做了什么

在 SMW5 上建立阶段 07 的隔离工作目录，同步阶段 06 冻结 CSV 和四个师兄聚类源文件。执行器固定 `PYTHONHASHSEED=0`，比较四个变体，并用同一输入生成聚类、bin 映射、初始状态、自信息分数和分区统计。

## 为什么这么做

阶段 08 的两层 UCB runner 需要稳定的 bin-to-cluster 输入、初始覆盖向量和静态信息先验。所有输入来自阶段 06 的 AON Timer 真实 VCS/URG 结果；没有引入 Bayesian training、UART 数据或旧项目结果。

## 怎么做

- 输入：阶段 06 的 `coverage_bin_by_run.csv`，39 个接受 run、4507 个 canonical bins，SHA-256 为 `71c02be6b80cb63973eeb96b26340f7e1d1ae2246674d148774c39c616ff1e94`。
- 环境：SMW5，项目 `.venv` Python 3.11.7；算法源 SHA-256 见 `evidence/stage07_clustering_20261102/variant_summary.json`。
- 命令：`PYTHONHASHSEED=0 python run_stage07_clustering.py --input coverage_bin_by_run.csv --source-dir source --output-dir <stage07-evidence> --max-cluster-size 256 --seed 0`。
- 选择规则：依次最小化超大 cluster 数、singleton 数、cluster 总数，最后按变体名排序；不使用覆盖结果挑选变体。
- 评分：self-information 为 `-log(39-run frequency)`；cluster 静态权重为 cluster 内平均自信息除以正 cluster 分数均值并截断到 `[0.25,4.0]`；覆盖由 hit count > 0 判定。

## 文件放哪里

执行器位于 `tools/run_stage07_clustering.py`；公开证据位于 `evidence/stage07_clustering_20261102/`。商业仿真数据库、simv、许可证和完整日志只保留在学校服务器隔离目录。

已完成独立校验：映射 4507/4507，唯一 cluster ID 78，矩阵 39×4507，所有 4507 个分数有限；选定 `dbscan_clustering_new2`，78 个 cluster，大小 2–218。初始覆盖并集为 233 bins（5.1697%）。服务器端再次读取 CSV/JSON 并检查行数、cluster bin 总数、分数非负和映射完整，返回 `STAGE07_INDEPENDENT_CHECK_OK`。本阶段只生成调度器离线输入，不代表论文表 II 结果；阶段 08 仍需真实连续补位仿真。
